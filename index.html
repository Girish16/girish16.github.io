PRODUCTION DATA

Tracing failures across banking systems

Following a data discrepancy from the first alert through APIs, queues, and databases to identify where processing broke down.

  • SQL
  • Message queues
  • Production monitoring
Read case studyClose case study

The problem

Customer and transaction data pass through several services. When a downstream record is missing or out of sync, the symptom alone rarely identifies the failed step.

My approach

I use SQL to compare records across systems, then trace requests and messages with logs and correlation IDs. After remediation, I validate the affected records and check that processing has resumed.

Illustrative incident workflow

  1. Trace the request
  2. Reconcile records
  3. Validate the fix

APPLIED AI

Retrieval for a RAG application

Building the retrieval layer that finds relevant source material before a language model generates an answer.

  • Hugging Face
  • OpenSearch
  • Vector search
Read case studyClose case study

The problem

A retrieval-augmented application needs a way to find relevant source material even when the query and the document use different words.

My approach

At Kagool, I implemented a RAG architecture using Hugging Face embeddings and OpenSearch vector search. The retrieval layer searches for semantically related passages and passes them to the model as context.

Retrieval and generation workflow

  1. Embed the query
  2. Search the index
  3. Pass relevant context

My approach

At Kagool, I set up MLflow Tracking and Model Registry, then added automated promotion checks for schema compatibility, minimum performance thresholds, and bias screens.
